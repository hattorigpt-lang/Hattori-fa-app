# FIRE & 資産運用 ライフイベントシミュレーター

資産推移・FIRE達成年齢・老後の取り崩し可能額を、ライフイベントとNISA・売却時課税まで織り込んで試算するブラウザアプリケーションです。

---

## 起動方法

ES Modules を使用しているため、`file://` での直接オープンでは CORS により動作しません。ローカルサーバー経由で開いてください。

```bash
# いずれかの方法で起動
python3 -m http.server 8000
npx http-server -p 8000
```

ブラウザで <http://localhost:8000/> を開きます。

## ディレクトリ構成

```
.
├── index.html              マークアップ（ロジックを含まない）
├── css/
│   └── style.css           デザイントークンとコンポーネントCSS
├── js/
│   ├── main.js             エントリポイント。各モジュールの配線のみ
│   ├── config.js           定数・初期値・入力の許容範囲
│   ├── state.js            単一状態ストア（購読／バリデーション）
│   ├── persistence.js      localStorage 保存とURL共有
│   ├── simulator.js        計算エンジン（DOM非依存の純粋関数）
│   ├── formatters.js       表示用の整形関数
│   └── ui/
│       ├── dom.js          DOM操作ヘルパー
│       ├── inputs.js       入力フォームのバインディング
│       ├── events.js       ライフイベント表（差分レンダリング）
│       ├── kpi.js          サマリー・KPIカード・警告
│       ├── tables.js       シナリオ比較表・年次明細
│       └── chart.js        Chart.js ラッパーと注釈描画
└── tools/
    └── verify.mjs          計算エンジンの回帰検証（Node）
```

### 設計方針

| 方針 | 内容 |
|---|---|
| 計算とDOMの分離 | `simulator.js` は DOM に一切依存せず、入力オブジェクトから結果オブジェクトを返す純粋関数のみで構成。Node からそのまま検証できます。 |
| 単一状態ストア | 状態の書き換えは `state.js` の `patch()` / `replace()` 経由のみ。グローバル変数への直接代入を排除しています。 |
| 宣言的なバインディング | HTML 側の `data-field="キー名"` が唯一の接点。要素IDを個別にキャッシュする必要がありません。 |
| 差分レンダリング | ライフイベント表は行を再利用し、グラフは `destroy()` せず `update('none')` で差分更新します。 |
| 定義の一元化 | 入力の許容範囲・FIRE目標タイプ・シナリオ定義は `config.js` に集約し、HTML と JS の二重管理を避けています。 |

## 計算モデルの前提

### 資産バケット

| バケット | 利回り | 課税 |
|---|---|---|
| 現金・預貯金 | 0%（固定） | なし |
| NISA口座 | 株式と同率 | 非課税（生涯枠1,800万・年間枠360万） |
| 株式・投信（課税口座） | 入力値 | 売却時に含み益へ 20.315% |
| その他運用資産 | 入力値 | 売却時に含み益へ 20.315% |

### 主要ルール

- **課税は売却時のみ。** 運用中は非課税で複利が働き、取り崩した金額のうち含み益に相当する部分にのみ課税します。取得原価は売却比率で按分して減額します。
- **積立順序** は NISA枠 →（枠を使い切ったら）課税口座。
- **取り崩し順序** は 現金 → 課税口座 → その他 → NISA。非課税の複利を最後まで温存する順序です。
- **FIRE達成判定** は、含み益への将来の税負担を差し引いた「税引後の実質資産」で行います。
- **シナリオ比較** は市況全体の想定として、リスク資産の利回りを一律に ±2 ポイントシフトさせます（標準＝入力値）。
- **「リタイア後に使える月額」** は、年金・インフレ・ライフイベント・売却時課税をすべて織り込んだうえで、想定寿命の時点で資産がちょうど尽きる水準を二分探索で逆算した値です。今日の物価に換算して表示します。

## データの取り扱い

入力内容はブラウザの `localStorage` にのみ保存され、外部へ送信されません。「条件を共有」で生成されるURLは、状態を base64url へエンコードしてハッシュ部（`#`以降）に格納するため、サーバーへは送信されません。
